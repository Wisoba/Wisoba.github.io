PINCR · Security

Report a suspected security issue directly.

Email security@getpincr.com with the affected component or URL, reproduction steps, impact, and safely shareable evidence.

Scope and handling

Reports may concern RF, published installation material, this site, or a PINCR-controlled service. PINCR records each finding as resolved, accepted, mitigated, or blocking. Do not include secrets or customer data in an initial report.

Please allow reasonable time for investigation before public disclosure. No response-time, bounty, or disclosure deadline is promised.
